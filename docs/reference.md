# Reference

The guides show how to build and run an admin. These pages hold the
exact contracts behind them: open a guide first, then its reference
when you need the precise shape, key or bound.

- {doc}`rest-api` — every route, the envelopes, the values on the wire,
  the list grammar and the errors.
- {doc}`configuration` — every environment key and UI setting.
- {doc}`limits` — the bounds Vector enforces and the guarantees it
  keeps.

The package's own README and `docs/` in the repository hold the same
contracts in developer form, alongside the descriptor's JSON schema
(`packages/vector/resources/schema/descriptor.schema.json`).
